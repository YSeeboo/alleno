# 订单批量操作：本地实施与验收

日期：2026-11-26。以下为最初「在本地实现」的历史验收记录；用户随后已授权合并、推送并部署正式服，发布范围及隔离核对见文末。工作区其他未提交功能保留，不回填业务数据。

## 已接入真实页面

- `/orders/:id` 商品表增加「全部／尚待备货」筛选，仅过滤显示，不改变明细、汇总、预留或出货。已有 `gap` 不为 0 的商品保留；历史未核对或异常的未知缺口仍保留，并明确提示待核对。切换订单恢复「全部」。
- `/orders/:id/production` 生产需求增加逐行勾选和全选，批量为同一商家新建一张手工单，或明确追加到一张同商家、未归档、未发出的手工单。原单条制作入口保留。
- 批量制作弹窗分别填写各行整条制作计划、本单份额及材料。默认只参考剩余生产需求，不根据尚待备货量自动排产。重复商品订单行、产出和材料均不合并；BOM 按商品去重读取，但每条订单行持有独立材料草稿。BOM 缺失／失败必须手动核对，旧参考批次须确认已核对历史加工和库存。
- 「订单关联」升级为跨手工单多产出勾选、按单选择和当前筛选全选。筛选不清除隐藏的选择或草稿；新选产出默认保留原本单份额，不自动补满。集中编辑各条产出的分配后数量，实时核对来源容量和精确订单行需求合计，合计包含未选产出的已有份额。
- 原单来源调整入口仍用原接口。批量分配复用 `POST /orders/{id}/production/batch`，统一替换所选来源的本单份额，允许填 0 释放或在来源间搬移；其他客户和未选来源不变，任一失败整批回滚。取消不写入；保存失败保留草稿，保存中禁止重复提交和路由离开。
- 生产页面各外层模块独立展开／收起，支持全部展开／收起，使用 `v-show` 保留内容和草稿。浏览器保存键为 `allen:order-production-sections:v1`；存储不可用不影响操作。历史入口和手工／电镀深链自动展开目标。加载失败、BOM 缺失、旧归属冲突、原产出变更等摘要在收起时仍可见。

## 接口与事务边界

新增 `POST /api/orders/{id}/production/handcraft/batch`，同时要求订单与手工权限。请求为 `OrderHandcraftBatchCreate`，含 1–100 个唯一 `allocations`，与 `jewelries` 按位置一一对应；每个订单明细创建一个独立新产出。

单条与批量创建共用 `services/order_production_creation.py` 的校验、客户订单锁、追加父单锁和 savepoint。追加不会合并旧材料／产出，也不改原日期和收货码；新建、逐行份额和商家登记一起成功或回滚。复用既有 `ProductionCreation` 请求指纹和回执，不新增数据库表；相同请求重试返回原结果，改变请求内容拒绝。

保存中或断网／服务异常导致结果不确定时冻结原请求和请求键，禁止关闭、Escape、路由离开及同路由切单，刷新触发离开提示。原请求可准确重试，避免重复建单。**不保证强制刷新后恢复待核对请求**：如强制刷新、关闭或退出登录，须先查原单据，不应直接发新创建请求。

以上操作只改变制作计划与数量份额，不发料、不预留、不扣库存、不入库、不修改实收和客户出货。

## 配件备料模块合并

- 将「配件备料需求」与「配件备料与 BOM」合为一个「配件备料」模块，置于本单生产需求之后。主表按精确订单行保留商品／客户货号、所需配件、单件用量、订购、理论需求、已安排和核对信息，不合并重复商品行。
- 生产页面直接使用同一次生产接口返回的 `materials`，不另读商品 BOM 重算当前需求。BOM 删除后仍有保存需求／安排的行继续显示；无当前 BOM 的商品明确提示，BOM 变化和旧归属冲突可同时展示。商品详情的物料工具仍可独立查看 BOM，但未读取生产份额时显示「—」，不伪装成已安排 0。
- 组合配件 BOM 改为行内展开，按配件去重读取、失败可重试，切换订单后忽略旧请求；子配件只作单件参考，不再计入当前需求。裁剪统计、配货模拟／PDF 保留在标题右侧。
- 原备料估算默认收起，与当前需求分开加载；估算或配件目录加载失败不遮蔽生产接口已返回的需求和安排。已有批次与生产关联记录仍为独立模块，历史入口直接展开该模块，不再联动展开备料主表。
- 沿用浏览器折叠键；首次迁移时仅当两个旧模块均已收起才收起合并模块，随后以新标题的设置为准。
- 验证：前端全量 **520 passed，0 failed**；`npm run build` 与 `git diff --check` 通过（仍有既有 `auth.js` 混合导入提示）。浏览器核对真实隔离预览中的单一主表、桌面／390px 手机无页面横向溢出、独立折叠持久化、裁剪和配货弹窗。组合行展开另以浏览器内存中的临时组合标记验证，刷新即恢复，未写数据库；子 BOM 读取后没有新增需求。
