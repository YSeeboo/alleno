# 电镀／手工允许超量回收

## 业务规则（2026-11-18）

- 电镀回收、手工回收的新建、追加、数量修改均允许累计回收超过来源发出／计划数量；电镀发出详情的「关联回收单」使用同一规则。
- 来源原数量不改写。按每次真实回收数量入库及计算七位小数金额，修改／删除只冲回对应真实数量；不会虚构回收记录、额外发料、自动退料或材料库存。
- 正数、手工产出整数（含组合配件产出）、商家及回收配件一致性、已付款锁定、归档保护不变。损耗仍只能确认真实未结清部分，不因允许超收而放开损耗上限。
- 已收足、已超收及已完成单据的合法已发出明细仍可选择。待发出及已归档来源不可选择。同一回收单已有来源仍从追加选择器排除，改原明细数量即可；其他回收单可继续使用此来源。
- 未收量最低为 0，显示来源结清超出量；结清计数包含已确认损耗，因此不将「结清超出」错误称为纯实收超出。电镀发出详情仍独立显示实收／损耗，并标示真实实收超出。
- 有剩余的来源默认填剩余量；已结清来源默认留空，用户必须输入实际正数，不擅自默认回收 1 或 0.0001。配件退料弹窗保留勾选但尚未填写的项目并阻止确认，不静默丢弃。

## 选择 API 的兼容边界

`GET /api/plating/items/pending-receive` 和 `GET /api/handcraft/items/pending-receive` 新增可选 `include_settled=false`。

- 默认仍返回未结清项，避免改变现有汇总／其他调用者语义。
- 回收录入页面显式传 `include_settled=true`，纳入正常已发出、进行中／已完成来源；保留商家、关键词、日期、回执编号及排除来源 ID 筛选。
- 不修改旧看板 `VendorReceipt` 数据格式，不做历史记录转换或回写。

## 手工材料不足与撤回

- 自动耗料仍按 BOM，仅核销本单实际已发出且未结清的材料容量；不足部分保留提示，不借用其他库存或伪造发出量。
- 调低／删除产出回收时，先更新来源产出结清计数，再按**全部仍保留产出（含确认损耗）**计算共享材料需求。只撤销超过剩余需求的既有耗料，且不超过本次减少产出对应的 BOM 需求。
- 同款重复产出行、不同饰品和组合产出共享材料一起计算；不撤回退料，不抵消其他产出或已确认损耗所需耗料，不移动材料库存。
- 例如发出材料 10、收到产出 12、每件耗料 1：耗料为 10；改收 10 时仍耗料 10，改收 8 才撤回耗料 2。
- 手工完成仍按产出逐项结清判断，材料余额不阻塞；减量到未结清后恢复进行中。见 [handcraft-summary.md](handcraft-summary.md)。
