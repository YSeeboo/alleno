# 配件类目

- 可选类目：吊坠／挂件、链条、扣具、连接件、耳饰配件、珠子／散珠、底托／镶嵌件、线材／绳带。类目不代表颜色、计量单位或是否为组合件。
- 配件列表可按类目筛选；「待细分」显示旧「小配件」及没有有效类目的记录。不会自动重分类旧料。
- 列表和详情可修改单件类目；列表「批量归类」只更新显式选中的编号，最多 500 个/次。应一起整理的原色、镀色件或变体可一并勾选；不会自动改动未选中的配件。创建变体与创建整件电镀收回件仍默认继承源类目。
- 单独改类目不改编号、库存、BOM、成本、计量单位、手工加量规则或历史单据。原有类目的新建编号格式保留，六个细分类目共享 `PJ-` 流水号；不要用编号推断当前类目。
- Excel 模板的类目列与页面共用选项，旧表格的「小配件」仍可导入。Excel 仍按原规则通过编号或同名同类目匹配，不会给已有配件重新归类；整理旧料请使用「批量归类」。
- 无数据库结构迁移；本地测试只使用独立测试库。
