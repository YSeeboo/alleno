# 订单管理与新建订单 · 独立 UI 预览

## 审阅入口

- 订单管理：`http://localhost:5173/demos/order-management/index.html#/orders`
- 新建订单：`http://localhost:5173/demos/order-management/index.html#/create`
- Demo 评审阶段只新增独立 Demo、对应测试和本文档；当时未修改真实页面、应用路由、后端或业务数据。用户随后确认按此方案修改真实列表／新建，现已完成该前端接入，见 `docs/order-production-implementation.md`。本目录 Demo 保持隔离、不被真实页面引用。

## 设计方向

沿用已确认订单详情的深色 240px 侧栏、AL／ALLENOP 品牌、浅灰背景、绿色主操作、轻量区块和细边框表格。不新增底部悬浮操作栏，也不借 UI 优化扩大业务字段。

### 订单管理

- 标题右侧保留刷新／新建订单；分隔式概况展示全部演示数据的订单总数和待生产／生产中／已完成笔数，不把历史完成笔数冒充真实实发。
- 状态快捷筛选、订单／客户搜索、仅历史待核对筛选、日期／金额排序及分页。
- 订单号与客户合并展示；条码标记轻量化。订单状态、足量交付、待发预留分别表达；不同单位不混加，部分发货不计完整交付。
- 金额明确标注为商品金额，不含后续包装费。查看可打开订单速览；完整详情沿用此前已确认方案，本次不再重做。

### 新建订单

- 客户名称／可选创建日期／是否条码，饰品明细与配件明细分区；不增加交期、库存预留或生产计划输入。
- 商品选择带入参考单价，可编辑数量、最多七位小数单价和明细备注；同款可加多行，行身份独立。可只创建饰品或只创建配件订单。
- 桌面右侧显示普通文档流汇总，手机排到明细下方；实时小计使用七位定点运算，各单位分别汇总。
- 标题「创建演示订单」校验后添加到当前内存列表，显示演示成功说明；无实际库存、生产或出货动作。返回列表再回来时保留尚未提交的内存表单，不声称服务端已保存草稿。
- 新建页默认填入可编辑虚构示例，可点「清空表单」查看空状态，也可重新填入示例。

## 安全边界

- 只使用本目录独立虚构数据模块和上一版 Demo 的视觉 CSS；不引入真实业务引擎。
- CSP 禁止网络数据连接和表单外发。无认证、API、上传、浏览器存储或数据库写入；刷新全部重置。
- 真实历史订单的删除入口及后端删除预检仍留在真实应用，本 Demo 不执行删除业务订单；只演示新增表单行删除。
- 真实页面已在用户评审确认后另行实施，沿用 Naive UI、真实目录／接口及成功详情导航，不引入 Demo 样本／重置工具或演示成功弹窗。未提交、推送或部署。
