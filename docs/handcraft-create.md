# 新建手工单

## 本轮范围（2026-11-24）

- 正式入口 `/handcraft/create`：制作信息、批量产出、分组 BOM 发料与提交前核对。
- 批量选品只编辑本地草稿，支持饰品和组合配件、筛选、统一数量；取消不改主单。已有产出须在主单确认移除，避免静默丢失手动发料。
- 数量输入即时同步，并保留提交前失焦与 Vue 更新边界。自动材料随产出数量变化；手动实际数量保留，理论用量仍联动，可恢复自动数量。
- BOM 空、加载中和失败独立展示；失败可重试且阻止提交。补充材料独立列示，不修改商品 BOM；按单位分别汇总，不合并来源行。
- 默认新建独立待发出单；追加必须明确选择同商家待发出单。换商家或处理方式时清空目标，沿用原创建 API，不扣库存、不预留客户库存、不自动发出。
- 成功后保存单号阻止重复提交；超时或不确定服务端结果暂停重试，明确校验失败保留草稿并允许修正。
- 桌面右侧核对，平板单列，手机固定底部核对；选品与核对弹窗短屏内容可滚动、操作保持可见。
- 包含此前产出删除即时移除及刷新列表、统计、分拣的修复；删除成功但刷新失败时不误报删除失败。
