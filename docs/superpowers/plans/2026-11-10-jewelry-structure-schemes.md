## 1. 数据与解析层

1. 用结构、稳定位置、搭配方案及差异模型替换旧模板模型，不受旧模板格式兼容约束；保留实际饰品和 BOM 的行为。
2. 设计创建来源记录和批次幂等记录；明确修订号更新规则。
3. 编写结构保存、方案保存、兼容性检查和 Decimal 用量解析测试，再实现服务。
4. 预览与创建共用解析逻辑；服务端拒绝跨结构位置、失效方案和非法配件 / 用量。
5. 新流程只创建新饰品，用现有编号规则写入饰品和实际 BOM；不新增库存流水。
6. 编写显式旧模板清理 / 新结构建表迁移：审查外键及引用，先清理旧模板配件行再清理旧模板；无需迁移旧模板数据。不得使用宽泛级联清空，也不得在每次启动时清理。

完成标准：新结构可在测试库中独立验证；旧模板全部清理后，已有饰品、实际 BOM、库存及历史单据保持不变。

2. 接入现有权限体系，明确维护配置与创建饰品的权限边界。
3. 批次创建使用统一事务，创建前检查本批所有行。
4. 加入预览修订校验与确认幂等键，覆盖并发变更、重复确认及超时重试。
5. 用真实 commit / rollback 测试路径检查中途失败无残留。

完成标准：权限、归属、事务、重复提交和陈旧预览测试通过。
