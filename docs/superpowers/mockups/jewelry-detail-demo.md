# 饰品详情 · UI Demo

本地入口：<http://127.0.0.1:5176/demos/jewelry-detail.html>。

后续状态：用户确认保持这版交互后，已接入本地真实饰品详情；批发价仍在底部“编辑价格”中修改。接入范围与验证见 [饰品详情页](../../jewelry-detail.md)。下文“不替换真实页面”描述的是独立 Demo 阶段的边界。

源文件：`frontend/public/demos/jewelry-detail.html`。内置示意图位于同目录的 `assets/`，无第三方字体、脚本或图片依赖。可以直接打开 HTML；通过现有 Vite 服务打开时布局和复制编号体验更完整。

## 设计方向

对齐 `frontend/src/views/plating/PlatingDetail.vue`：深色导航、浅灰背景、绿色强调、小面包屑、标题旁状态、连续统计栏、轻量分区标题、细边框明细表，以及底部深色浮动操作栏。不照搬电镀业务进度条。

- 统计栏：库存、物料成本、手工费、总成本、零售价。
- 基本信息：放大饰品图，支持切换结构图；编号、类目、计量单位、颜色、批发价、配件种数集中展示。
- BOM：缩略图和编号同列，用量可直接修改，成本小计及物料合计同步演示，支持配件搜索和增删。
- 底部：查看库存、启用/停用、编辑价格、添加配件。
- 窄屏：导航收起，统计栏换行，图片与基本信息上下排列，BOM 只在表格内部横向滚动。

不加入尚未确认的系列/别名设计，也不更改现有饰品详情、列表、路由、权限或业务接口。

## 可体验内容

1. 修改 BOM 用量，按 Enter 或失焦确认，观察成本同步变化；库存示例不变。
2. 搜索配件，添加新配件，移除配件前确认。
3. 编辑名称、类目、颜色及单位；“卡”可选，类目不会覆盖单位。改变单位标签不换算数量和价格。
4. 修改售价、批发价或手工费，切换启用/停用状态。
5. 切换饰品图/结构图，点击放大；更换图片仅通过本地对象 URL 预览，不上传。
6. 顶部切换“完整成本 / 成本待补全 / 暂无 BOM”。缺失成本不当成零成本；仅展示已知物料小计，完整成本暂留空。
7. 使用“重置”恢复当前场景，或刷新恢复默认场景。

## 边界

- 所有编号均使用 `DEMO-` 前缀；库存、价格、配件和用量为虚构示例。
- 图片为绘制示意，不代表真实商品照片、实际配方或生产尺寸。
- 所有修改仅存于页面内存，不读写数据库，不调用业务 API，不存储到 localStorage。
- 成本联动只用于 UI 演示，不取代正式服务端成本计算。库存弹窗是虚构流水，不提供真实库存操作。
- 导航菜单为演示；仅明确的“返回饰品列表”链接跳转到本地业务列表。
- 本次未替换现有详情页，未提交、推送或部署。
