# 饰品类型与计量单位

## 规则

- **类目回答“是什么”**：耳饰、项链、手链、戒指、胸针、发饰、组合套装、其他。
- **计量单位回答“按什么计数”**：个、对、条、枚、件、套、卡。同一类目可以使用不同单位，例如耳饰按对、按个或按卡计量。
- 类目与单位分别选择，修改类目不再自动填写或覆盖单位。
- 新类目使用统一的 `SP-00001` 流水编号，不再将分类编码进新编号。分配流水沿用数据库原子计数器，删除后不复用；初始化时避开已有编号。
- 修改类目只改当前饰品的分类元数据，不重新编号、不转换单位、不修改 BOM、价格、库存、订单引用、同款成员或历史创建快照。
- 复制和添加同款默认继承原类目、单位，也允许显式重新分类；BOM 仍原样复制，不自动按单位换算。

## 旧数据过渡

- 不执行启动清理或批量更新。不自动把旧“单件”“单对”“套装”猜测成新的饰品类型。
- 列表和详情将旧值显示为 `待分类（原：单对）` 等，空类目显示为 `待分类`；列表的“待分类”筛选包含这些记录。
- 在编辑窗口中选择明确的新类目后保存，已有编号（如 `SP-PAIR-00001`）保持不变。旧编号前缀不再代表当前分类，分类应读取 `category` 字段。
- 新增、复制、同款与结构工作台的界面只提供新类目。旧结构显示待分类提示，保存结构或预览新批次前需显式选择饰品类型与计量单位；修改结构不会自动修改已有饰品。
- 为保持旧客户端、已保存结构、幂等重试与历史快照可读，后端过渡期仍接受三个旧类目值；旧客户端按旧值新建时保留旧前缀。该兼容行为不自动迁移数据，也不是新界面的推荐分类。

## 单位注意事项

库存数量、单价与 BOM 均以一单位饰品为基准。例如单位为“对”，BOM 的耳针用量 2 表示每对使用 2 个耳针。

改变单位名称**不会**执行换算。例如把“对”改为“个”，系统不会自动把库存乘 2、价格除 2，或把 BOM 除 2。已有业务记录不应仅通过修改单位标签来改变计量基准；需要另行明确换算和历史处理方案。
