# 订单详情 UI · 电镀风格独立预览

- 新版：`http://localhost:5173/demos/order-detail-plating/index.html`
- 上一版：`http://localhost:5173/demos/order-integration/index.html`，原文件不变。
- 本次只新增 `frontend/public/demos/order-detail-plating/`、对应测试及本文档，不修改真实订单页面、路由、侧栏、接口或数据库。
- 保留现有「商品详情／生产安排／订单信息」三个 Tab。点商品名可预览商品详情弹窗。

## 视觉方案

参考 `frontend/src/views/plating/PlatingDetail.vue` 和电镀管理的视觉层级：

1. 保留深色侧栏、AL / ALLENOP 品牌、绿色强调和浅灰页面背景。
2. 紧凑标题及状态胶囊，商品详情 / 生产安排 / 订单信息三个页签，顺序与真实页面一致。
3. 商品页用一条分隔式统计栏取代多张独立统计卡；不混加不同单位的数量。完整资料不再挤入商品页。
4. 订单信息页单独展示基本信息、条码、唛头、参考图和备注；支持编辑客户名称、创建日期及订单要求。
5. 商品表使用浅表头、细边框、缩略图、客户货号与实发进度；行内只保留编辑及更多操作。
6. 商品页的出货记录与费用成本在桌面并排，操作历史可展开；完整要求与参考图只在订单信息中展示。
7. 不设底部悬浮操作栏：商品页右上角提供「新建出货单」主按钮，「物料工具／添加商品」放在商品明细标题旁；生产操作和资料编辑保留在对应区块。出货记录保留轻量的新建入口。
8. 手机统计栏重排，页头按钮独立一行；商品列固定、明细表横向滚动；其他区域不产生页面级横向溢出。移除为悬浮栏预留的底部大块留白。

不套用电镀的线性工序步骤条：现货出货不要求先生产。也不新增真实订单模型中没有的交期字段。

## 交互与业务边界

可预览商品详情、编辑/新增商品、七位小数单价、客户/创建日期/条码/唛头/备注、包装费、预留/释放、生产来源追溯、明确新建/追加独立产出、本行生产份额、BOM 理论用量，以及出货草稿。

三个 Tab 支持独立 hash 直达、浏览器前进后退及键盘方向键/Home/End 切换；修改资料和要求后仍停留在信息页。历史信息页保持只读。

- 复用的只有之前 Demo 的虚构内存引擎，完全不引入业务应用模块。
- 新建出货只保存演示草稿，不提供实际出货确认；不占库、不扣库。
- 历史订单显示未核实，不补造实发、入库或生产份额；此版不提供历史启用操作。
- 生产计划、配件计划、实际发料、成品预留、客户实发分别展示。
- BOM 是理论用量，不是已结算实耗；成本未结齐时不显示实际利润。
- 裁剪/领料 PDF 等真实工具没有被移除；本视觉 Demo 不生成业务凭据，也不上传真实附件。
- CSP 禁止连接和表单外发；没有 API、认证、浏览器存储或持久化。刷新即重置。
