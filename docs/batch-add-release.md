# 批量添加与详情体验更新

## 本次范围

- 六个批量添加入口：电镀配件、手工产出、手工配件、订单商品、饰品 BOM、采购追加配件。统一选品与逐行编辑，保留各入口的状态限制、独立明细和失败反馈。
- 手工待发出单追加产出时，追加其直接 BOM 材料，不覆盖已有手动材料；电镀与手工配件默认沿用商品单位。
- 电镀新建回收单只列尚未完全回收来源，并支持在来源行填写回收单价，与已选明细同步。
- 配件详情切换同族商品时重新加载，并忽略旧请求结果。
- 手工／电镀的生产计划用途改为默认收起摘要，保留风险提示和订单跳转。
- 客户货号连续编号弹窗紧凑化，保留编号顺序、覆盖规则及原保存接口。
