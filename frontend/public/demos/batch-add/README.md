# 批量添加 · 布局提案

本目录是隔离的静态交互 Demo，不改生产组件，不读取业务数据，不调用接口，也不持久化草稿。

启动现有前端开发服务后打开：

`http://localhost:5173/demos/batch-add/index.html`

必须使用 `index.html` 完整路径（Vite 开发服务的目录路径可能回退到主应用）。支持链接参数，例如 `?plan=C&scene=plating`。

## 三个方案

| 方案 | 布局 | 适用特点 |
| --- | --- | --- |
| A：左选右编（推荐） | 左侧搜索、多选商品；右侧直接编辑待添加行 | 数量和业务字段同屏可见，适合默认通用入口 |
| B：图片选品 | 图片卡片多选 + 底部暂存条，再进入宽表完善明细 | 饰品、组合配件等看款式选品的场景 |
| C：分步批量 | 第一步选品，第二步集中编辑、确认 | 电镀颜色等字段较多，或一次加入较多行 |

已选定 A 作为后续开发方向。三个方案仍保留供对比，共用同一场景草稿，已选和已填内容不丢失。切换业务场景会重置为该场景的两条示例。适配窄屏；A 在窄屏上下排列，明细宽表可横向滚动。

A 的待添加清单中，1–3 个主要字段按实际字段数在同一行排列，不让电镀颜色单独占一行；对应配件提示与选填重量/备注仍在下方。

## 可体验

- 搜索、按商品类型筛选、只看已选、全选当前筛选结果。筛选不清空已选。
- 单行数量、单位与场景业务字段编辑；统一填数量；电镀统一应用颜色。
- 电镀颜色沿用原页面的标签选择方式：G（金色）、S（白K）、RG（玫瑰金）直接点选，“更多”展开 K14（14K金）与 SV（银色）；不使用颜色下拉框。每行可独立选择，也可统一应用。
- 暂存、移除、清空、选填重量/备注、返回选品、模拟统一添加与完成结果。
- 订单添加时不填写客户货号，只保留数量、单位、单价一行；货号可之后在订单详情统一维护。同款“再加一行”仍保留独立明细。
- BOM 小数用量、已有配件禁选；不显示金额或库存写入动作。
- 电镀颜色缺少对应配件时阻止模拟提交，并保留全部输入。示例：天然淡水珍珠改选 S / RG。
- 空数量、非法小数、负价格等校验；7 位小数单价、0 单价；不同单位分开汇总。
- 场景盘点说明可从页头打开。

## 入口盘点

| 入口 | 现状与本次建议 | 源文件 |
| --- | --- | --- |
| 电镀单 → 增加配件 | 单条表单；需适配颜色/对应配件、单位、可选重量/备注 | `src/views/plating/PlatingDetail.vue` |
| 手工单 → 添加产出 | 单条表单；饰品/组合配件、默认单位、BOM 材料追加影响 | `src/views/handcraft/HandcraftDetail.vue` |
| 手工单 → 添加配件 | 普通选择是单条；“最近导入”已支持批量，其累加规则保留 | 同上、`src/components/RecentImportsPicker.vue` |
| 订单详情 → 添加商品 | 现有单条表单有客户货号；选定方案在添加时不填写，之后在详情维护；保留独立明细行与 7 位小数单价 | `src/components/fulfillment/OrderLineEditor.vue` |
| 饰品详情 → 添加配件 | 单条 BOM 用量表单；已在 BOM 中的配件排除 | `src/views/jewelries/JewelryDetail.vue` |
| **补充：采购单详情 → 追加配件** | 同类单条弹窗，建议纳入；数量、单位、单价、备注 | `src/views/purchase-orders/PurchaseOrderDetail.vue` |
| 新建订单、电镀单、手工单、采购单 | 不是弹窗，但仍需逐行选择，可在后续复用选品器插入草稿行 | 对应各 `*Create.vue` |
| 饰品结构工作台 → 单件调整 → 添加单件配件 | 也是逐行选品；需要保留组成位置、方案与单件覆盖关系，建议单独适配 | `src/views/jewelries/JewelryStructureWorkbench.vue` |
| 配件详情 → 子配件 BOM | 已有多项暂存、统一提交、复制 BOM；可复用选择界面，不需要重建提交业务 | `src/views/parts/PartDetail.vue` |
| 电镀 / 手工回收单 → 增加回收项目、新建回收单 | 已有多选；选择来源明细而非任意商品，回收数量、库存及成本确认不可替换 | 各 `*-receipts/*Create.vue`、`*Detail.vue` |

生产关联、实际出货、手动补货、库存调整不是本次商品库批量添加的同一动作，不混合处理。

## 正式开发边界

- 复用的是选择框架、草稿编辑体验，不是强行共用所有业务 payload 和重复规则。
- 单据状态、权限、商品可用性、颜色对应关系需要在提交时重新校验。
- 批量写入需要评估原子批量接口或部分成功的行级反馈、防重复与失败行重试。Demo 不承诺现有单条接口已具备原子批量能力。
- 手工产出带来的 BOM 追加应沿用已修复逻辑，不能重复追加或覆盖手动配件。
- 订单同款独立行；BOM 不可重复；手工“最近导入”的已有项累加规则不外推到其他入口。
- 价格最多 7 位小数；BOM 用量最多 4 位小数；数量、重量与单位按各场景适配；不同单位不混算。
- “模拟添加”仅展示结果，不会改变真实单据、库存或成本。
