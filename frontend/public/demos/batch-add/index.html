入口盘点与适配边界

本次先选布局，不更改真实页面。以下按现有代码梳理，不把“批量选择”误当作所有窗口都执行相同业务。

本次 Demo 覆盖 · 6 个场景

入口逐行保留的内容特殊规则
电镀单 → 增加配件发出配件、颜色、对应配件、数量、单位、重量、备注对应颜色配件需独立校验；不能静默创建变体或改变发出状态。
手工单 → 添加产出饰品 / 组合配件、数量、单位、重量、备注产出关联 BOM 材料，应预览影响；生产安排不等于入库。
手工单 → 添加配件数量、单位、重量、备注保留“最近导入”原有批量入口与其累加规则；普通添加的重复规则另行适配。
订单 → 添加商品饰品 / 配件、订购数量、单位、7 位小数单价、备注添加时不填客户货号，之后在订单详情中统一维护；同款可分多行，不自动合并，不同单位不相加。
饰品详情 → 添加配件每 1 单位饰品的配件用量，支持 4 位小数不改库存；已存在的 BOM 配件不可重复添加。
补充：采购单 → 追加配件数量、单位、7 位小数单价、备注同类单条弹窗，建议一起适配；保留单据状态限制。

可后续复用的相关入口

新建订单、新建电镀单、新建手工单（产出 / 配件）、新建采购单：现有表格支持多行，但仍需逐行选择商品，可复用选品器，把选择结果先加入草稿。

饰品结构工作台 → 单件调整 → 添加单件配件：也是逐行选配件，但同时包含组成位置、方案与单件覆盖关系。建议后续单独适配，不能直接当作普通 BOM 追加。

已有批量能力 · 不重复建设

  • 配件详情 → 子配件 BOM：已支持暂存多项、统一提交与复制 BOM，可统一选择体验。
  • 手工单 → 添加配件 → 最近导入：已有勾选、改数量、批量加入，已存在项按其规则累加。
  • 电镀 / 手工回收单 → 增加回收项目，以及新建回收单：已有来源明细多选。来源单、实际回收数量、库存与成本确认不能被普通选品器替代。
  • 订单生产关联、实际出货、补货与库存调整属于不同业务动作，不建议混入本次“添加商品”。

正式开发时需要落实

重新校验状态、权限、重复行和颜色变体；批量接口的事务或部分成功反馈、防重复提交与失败行重试；保留已填写草稿。本 Demo 的“一次添加”只模拟前端交互，不代表接口已支持原子批量写入。
